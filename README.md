# AI 公众号创作工作流（公开版）

一个面向公众号与自媒体创作者的可配置 Skill：**首次回答 9 个问题，保存自己的创作配置；之后用 7 步流程完成选题、写作、检查和本地发布包。**

它不是一句“帮我写爆款”的提示词，也不承诺阅读量、涨粉或固定创作时长。它更像一套可重复使用的工作说明书和工具箱。

## 你能用它做什么

- 没有主题时，研究并推荐 3—5 个候选选题。
- 有主题时，生成标题池、正文、证据包、质量报告和发布说明。
- 改写旧稿，保留真实信息，调整结构、语言和读者行动。
- 将长文或口播稿按目标平台重新组织。
- 按需生成 HTML、封面和流程图；提供公众号 HTML 转换脚本。

## 安装

### 方式一：导入 `.skill` 安装包

下载 [create-wechat-content.skill](dist/create-wechat-content.skill)，在支持 `.skill` 的兼容客户端中导入。不同客户端的导入入口可能不同。

### 方式二：使用源文件目录

仓库中的 [create-wechat-content/](create-wechat-content/) 是完整技能目录，包含 `SKILL.md`、参考规则、配置模板和脚本。可将该目录交给支持 Skills 的 Agent 使用。

## 第一次使用

安装后对 AI 说：

> 首次配置我的公众号创作工作流。

AI 会一次询问以下 9 题：

1. **创作方向与读者**：写什么，写给谁，解决什么问题？
2. **本次主题与素材**：有题目和材料吗？没有时能否让 AI 选题？
3. **主目标与读者行动**：推荐、分享、搜索还是精准关注？
4. **工作文件夹**：素材与成品放在哪里？
5. **平台与格式**：微信公众号、小红书、知乎或其他平台？要 Markdown 还是 HTML？
6. **周期与时间**：单次、每天还是每周？是否另设定时任务？
7. **篇幅与形态**：多少字，教程、观点、案例还是故事？
8. **风格与禁忌**：希望像什么、不像什么，有没有参考文章？
9. **自动化边界**：只生成本地文件，还是另行授权推入平台草稿？

赶时间时，只回答第 **1、2、4、8** 题，其余可使用默认值。

也可以先填写 [公众号创作启动清单](create-wechat-content/assets/公众号创作启动清单_填写版.md)，再把答案交给 AI。

## 之后使用

> 按原配置，写一篇关于“我如何用 AI 整理读书笔记”的公众号文章。

已有配置会被复用，只需补充本次主题或变化，不必重新回答九题。

## 7 步创作流程

```text
定主目标
→ 诊断选题与证据
→ 生成标题池
→ 开头／骨架／正文
→ 三道质量检查
→ 排版与本地发布包
→ 可选的平台草稿推送
```

## 安全与责任边界

- 默认只生成本地文件，不自动设置定时任务。
- 推入平台草稿需要单独授权、合法工具与真实成功回执。
- **发表与群发始终由本人操作。**
- 不在配置中保存密码、令牌或平台密钥。
- 重要事实、数字、个人经历、封面裁剪与手机预览仍需人工复核。
- 不承诺曝光、点击、涨粉、收入或“每天固定几分钟完成”。
