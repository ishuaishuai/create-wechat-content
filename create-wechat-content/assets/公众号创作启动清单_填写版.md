# 公众号创作启动清单（填写版）

> 用法：一次回答 9 题。赶时间可只填 1、2、4、8，其余保留默认值。答完后，AI 即可按配置开始创作。

## 1．创作方向与读者

- 账号／创作者称呼：
- 主要创作方向：
- 写给哪类人：
- 希望帮他们解决什么问题：

## 2．本次主题与素材

- 本次主题（没有可留空）：
- 素材文件或链接：
- 没有主题时，是否允许 AI 研究并选择最优项：默认允许 / 只推荐，等我选择

## 3．主目标与读者行动

- 主目标（只选一个）：推荐冲量 / 社交分享 / 搜索沉淀 / 精准涨粉
- 希望读者看完做什么：关注 / 评论领取 / 转发 / 其他
- 如果有领取物，关键词与真实交付物是什么：

默认：精准涨粉＋关注。

## 4．工作文件夹

- 素材与成品放在哪个文件夹：

默认：配置所在目录下的 `wechat-content/`。

## 5．发布平台与交付格式

- 平台：微信公众号 / 小红书 / 知乎 / 其他
- 格式：Markdown / HTML / 纯文本 / 其他
- 是否需要封面：默认需要 / 不需要
- 流程类文章是否需要流程图：默认需要 / 不需要

默认：微信公众号＋Markdown，按需配图。

## 6．创作周期与时间

- 单次 / 每天 / 每周 / 其他：
- 希望完成的时间：
- 所在时区：

默认：单次，不自动创建定时任务。需要定时时，另行确认具体频率与时间。

## 7．篇幅与内容形态

- 预计篇幅：
- 教程 / 观点 / 案例 / 故事 / 由 AI 按主题判断：
- 是否准备做成系列：

默认：1500—2500 字，由 AI 按主题判断结构。

## 8．风格、参考与禁忌

- 希望具备的 3 个风格词：
- 喜欢的参考文章或账号：
- 不想要的表达、话题或营销方式：
- 是否需要固定署名或签名：

默认：清晰、口语化、有具体建议。

## 9．自动化边界

- 是否允许联网核验资料：默认允许 / 不允许
- 交付到哪里：仅本地发布包 / 授权推入平台草稿
- 平台凭证由当前环境提供，不填写在本清单中。

默认：只生成本地发布包，不推草稿。无论选择哪种，发表与群发始终由本人操作。

## 可直接复制给 AI 的简版

```text
1. 方向与读者：
2. 本次主题与素材：
3. 主目标与行动：默认精准涨粉＋关注
4. 工作文件夹：
5. 平台与格式：默认微信公众号＋Markdown
6. 周期与时间：默认单次，不定时
7. 篇幅与形态：默认 1500—2500 字
8. 风格、参考与禁忌：
9. 自动化边界：默认只生成本地发布包
```
