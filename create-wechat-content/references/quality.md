# 质量与安全检查

## 一、事实与标题

- [ ] 关键事实有来源、日期和适用范围；链接或文件真实可打开。
- [ ] 数字有单位、样本与时间范围；没有把目标写成实测结果。
- [ ] 标题承诺在开头和正文兑现，不制造虚假收益或焦虑。
- [ ] 区分事实、观点、推测和经验；个人经历没有由 AI 编造。
- [ ] 未知、限制和失败风险没有因压缩而删除。

## 二、普通读者友好

- [ ] 一段只承担一个信息任务，优先短句，删除重复与模板腔。
- [ ] 必要术语首次出现时用白话解释；类比不替代事实。
- [ ] 有真实自然的数字时才使用数字标题，不为了醒目硬凑。
- [ ] 有具体案例、数据、实测或独家细节，而非通篇抽象观点。
- [ ] 结尾前给普通人可执行的认知、判断标准或行动建议。
- [ ] 流程、对比和清单在有助于理解时配图，不做无效装饰。

可运行：

```bash
python3 scripts/check_article.py article.md --strict --require-advice
```

脚本只辅助检查。即使通过，也要人工复核事实、语境与平台预览。

## 三、转化与合规

- [ ] 每篇只设置一个主要读者行动；领取物真实存在且能够交付。
- [ ] 不强制转发、集赞，不虚构自动回复或“已经领取”。
- [ ] 不承诺曝光、点击、涨粉、收入或学习效果。
- [ ] 医疗、金融、法律等高风险内容不提供个性化诊断或收益建议；必要时建议咨询合格专业人士。
- [ ] 不侵犯版权，不抄袭标题与正文，不泄露他人隐私。
- [ ] 不在配置、正文、元数据或日志中保存平台密钥和个人敏感信息。

## 四、发布边界

- [ ] 本地文件生成不等于平台草稿成功。
- [ ] 平台草稿只有真实成功回执才能登记完成。
- [ ] 定时任务必须由用户明确设置；平台推送必须单独授权。
- [ ] 发表与群发始终由人完成。
- [ ] 发布前人工检查标题、封面裁剪、手机预览、原创声明与平台专有设置。
